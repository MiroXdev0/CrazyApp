# Nodren Roadmap

## Goal
Build a distributed compute fabric that merges multiple PCs into a single execution platform.

## Milestone 1: Foundation
- node registration
- worker heartbeat
- job submission
- result collection
- minimal controller/worker API

## Milestone 2: Scheduling
- resource-aware placement
- priority scheduling
- retry logic
- worker failure handling

## Milestone 3: Storage and memory
- job staging
- result storage
- checkpointing
- distributed memory regions

## Milestone 4: Observability
- cluster metrics
- node health
- logs
- dashboards

## Milestone 5: Platform features
- sandboxing
- security boundaries
- workload isolation
- remote deployment

## Milestone 6: Developer experience
- CLI commands
- SDK
- plugin interfaces
- automation workflows
