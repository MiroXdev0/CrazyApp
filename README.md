# CrazyApp

A multi-language project scaffold for desktop, web, backend, systems, and native code.

## Structure
- Frontend/Desktop for the Avalonia desktop app
- Frontend/Web for the browser app
- Backend for server and data services
- Core for C/C++ native logic
- Shared for common interfaces and contracts
- Tests for project validation

## Getting started
1. Open the solution in your IDE.
2. Build the desktop app or run the web app.
3. Use the backend and native folders for service and system logic.
